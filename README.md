# 🏦 Банковское приложение

Современное веб-приложение для управления банковскими операциями с красивым интерфейсом в стиле T-BANK.

## 📋 Описание

Банковское приложение на Spring Boot, предоставляющее полный функционал для управления:
- Счетами и картами
- Переводами и транзакциями
- Платежами и счетами
- Кредитами и вкладами
- Бюджетом и аналитикой
- Уведомлениями

Приложение поддерживает темную и светлую темы оформления, имеет современный и интуитивно понятный интерфейс с плавными анимациями.

## 🚀 Технологии

- **Backend**: 
  - Java 21
  - Spring Boot 3.5.7
  - Spring Security
  - Spring Data JPA
  - MySQL

## 🛠️ Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd Bank
```

### 2. Настройка базы данных

1. Создайте базу данных MySQL:
```sql
CREATE DATABASE bank_app CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

2. Обновите настройки подключения к БД в `src/main/resources/application.properties`:
```properties
spring.datasource.url=jdbc:mysql://localhost:3306/bank_app
spring.datasource.username=your_username
spring.datasource.password=your_password
```

### 3. Сборка проекта

```bash
mvn clean install
```

## ▶️ Запуск

### Через Maven:

```bash
mvn spring-boot:run
```

### Через IDE:

Запустите класс `com.bank.Bank.BankApplication`

### JAR файл:

```bash
mvn clean package
java -jar target/Bank-0.0.1-SNAPSHOT.jar
```

Приложение будет доступно по адресу: `http://localhost:8080`

## 🗄️ База данных

Приложение использует MySQL. Схема базы данных создается автоматически при первом запуске (Hibernate DDL auto). Также выполняется скрипт инициализации `data.sql` для добавления тестовых данных.

Основные сущности:
- User (Пользователи)
- Account (Счета)
- Card (Карты)
- Transfer (Переводы)
- Bill (Счета для оплаты)
- Loan (Кредиты)
- Deposit (Вклады)
- Budget (Бюджеты)
- Notification (Уведомления)

## 🔧 Конфигурация

Основные настройки в `application.properties`:

```properties
# База данных
spring.datasource.url=jdbc:mysql://localhost:3306/bank_app
spring.datasource.username=your_username
spring.datasource.password=your_password

# Hibernate
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
```
